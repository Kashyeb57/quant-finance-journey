T-Stats with the t-Test

The t-statistic feeds the t-test. When we compare a single sample's mean against a known population value, it's called a one-sample t-test — the t-distribution's answer to the z-test when σ\sigmaσ is unknown.

A worked example​

In the population, the average IQ is 100. A team of researchers wants to test a new medication to see if it has a positive, negative, or no effect on intelligence. A sample of 30 participants who took the medication has a mean of 140 with a standard deviation of 20. Did the medication affect intelligence? (C.I. = 95%, α=0.05\alpha = 0.05α=0.05.)

Given: μ=100, n=30, xˉ=140, s=20, C.I.=95%, α=0.05\mu = 100,\ n = 30,\ \bar x = 140,\ s = 20,\ \text{C.I.} = 95\%,\ \alpha = 0.05μ=100, n=30, xˉ=140, s=20, C.I.=95%, α=0.05.

① Hypotheses​

H0: μ=100H1: μ≠100{2-tail test}H_0:\ \mu = 100 \qquad\qquad H_1:\ \mu \neq 100 \quad \{\text{2-tail test}\}H0​: μ=100H1​: μ=100{2-tail test}

"Positive or negative effect" points both ways, so it's two-tailed.

② Significance level​

α=0.05\alpha = 0.05α=0.05

③ Degrees of freedom​

dof=n−1=30−1=29\text{dof} = n - 1 = 30 - 1 = 29dof=n−1=30−1=29

This is the crucial difference from the z-test: the critical value comes from the t-table at 29 degrees of freedom, not the fixed normal.

④ Decision rule​

A two-tailed test at 95% puts 2.5% in each tail. From the t-table at dof =29= 29=29, the critical value is ±2.045\pm 2.045±2.045 (a touch wider than the normal's ±1.96\pm 1.96±1.96, because the t has fatter tails):

if t<−2.045  or  t>+2.045, reject H0.\text{if } t < -2.045 \ \text{ or } \ t > +2.045, \ \textbf{reject } H_0.if t<−2.045  or  t>+2.045, reject H0​.

The rejection region is fixed by α before you see data. If the observed statistic lands in it — equivalently, once its p-value (yellow) is smaller than α (red) — you reject H₀. Switch to t and drag df down: the tails fatten, the critical value moves outward, and small samples get harder to call.

⑤ Calculate the test statistic​

t=xˉ−μs/n=140−10020/30=403.65=10.96t = \frac{\bar x - \mu}{s/\sqrt n} = \frac{140 - 100}{20/\sqrt{30}} = \frac{40}{3.65} = \boxed{10.96}t=s/n​xˉ−μ​=20/30​140−100​=3.6540​=10.96​

Since t=10.96>2.045t = 10.96 > 2.045t=10.96>2.045, we reject the null hypothesis. In fact 10.9610.9610.96 is so far into the tail it's off the right edge of the chart above — the p-value is minuscule.

Conclusion: the medication affected intelligence — specifically, it increased it (the sample mean of 140 sits far above the population's 100).

import numpy as np
from scipy import stats

# One-sample t-test from summary stats (we only have mean, s, n).
mu0, xbar, s, n, alpha = 100, 140, 20, 30, 0.05
dof = n - 1

t = (xbar - mu0) / (s / np.sqrt(n))
t_crit = stats.t.ppf(1 - alpha/2, dof)          # two-tailed critical value
p = 2 * (1 - stats.t.cdf(abs(t), dof))          # two-tailed p-value

print(f"dof            = {dof}")
print(f"t-statistic    = {t:.2f}")
print(f"critical value = ±{t_crit:.3f}")
print(f"p-value        = {p:.2e}")
print("decision       :", "REJECT H0 — medication changed IQ" if abs(t) > t_crit
      else "fail to reject H0")

# If you had the raw 30 data points instead, one call does it all:
# t, p = stats.ttest_1samp(sample, popmean=100)

From one sample to two: Welch's t-test​

The one-sample test generalizes to comparing two group means — does strategy A's mean return differ from strategy B's? The classic two-sample (pooled) t-test assumes both groups share a single variance and pools them:

t=xˉ1−xˉ2sp1n1+1n2.t = \frac{\bar x_1 - \bar x_2}{s_p\sqrt{\tfrac{1}{n_1}+\tfrac{1}{n_2}}}.t=sp​n1​1​+n2​1​​xˉ1​−xˉ2​​.

That equal-variance assumption almost never holds for financial series — a small-cap and a mega-cap do not have the same return volatility. Welch's t-test drops it, using each group's own variance and a fractional degrees-of-freedom (the Welch–Satterthwaite formula):

t=xˉ1−xˉ2s12n1+s22n2.t = \frac{\bar x_1 - \bar x_2}{\sqrt{\tfrac{s_1^2}{n_1}+\tfrac{s_2^2}{n_2}}}.t=n1​s12​​+n2​s22​​​xˉ1​−xˉ2​​.

Welch's is the safer default: it reduces to the pooled test when the variances happen to match and stays valid when they do not, at almost no cost. It is in fact SciPy's default — stats.ttest_ind(a, b, equal_var=False).

Why a quant cares​

The one-sample t-test is the exact tool for the most basic quant question — is this average different from a benchmark?

  • "Does my strategy beat zero?" or "does it beat the risk-free rate?" is a one-sample t-test on the return series, with μ0=0\mu_0 = 0μ0​=0 (or the benchmark). The resulting ttt is, up to scaling, the t-stat on the mean return — the number every performance report is quietly leaning on.
  • The IQ example's shape is every "too good to be true" backtest. A huge xˉ\bar xxˉ far above μ0\mu_0μ0​ produces an enormous ttt — which is a reason to check for look-ahead bias and overfitting, not to celebrate. A t-stat of 10 on a strategy usually means a bug, not an edge.
  • Degrees of freedom keep you honest on short histories. With few data points the critical value balloons (dof small ⇒ wider), so a two-year track record has to clear a higher bar than a twenty-year one — exactly as it should.
