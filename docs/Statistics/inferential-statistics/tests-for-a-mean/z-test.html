Hypothesis Testing and Statistical Analysis: The Z-Test

Once the hypotheses are set, you need an actual statistical test to turn data into a p-value. Which test you reach for depends on what you're comparing.

The family of tests​

TestUsed forLeads to
① Z-testan average (σ known, large sample)a z-score and p-value via the z-table
② t-testan average (σ unknown)a t-score and p-value via the t-table
③ Chi-squarecategorical dataa χ² statistic
④ ANOVAvariance across 3+ groupsan F-statistic

The first two both test an average — the difference is only whether you know the population's standard deviation. The z- and t-tests are the workhorses of this module; chi-square (categorical) and ANOVA (variance) come later.

When you may use a Z-test​

A z-test is valid only when both conditions hold:

(i)    the population standard deviation σ is known(ii)    n≥30\textbf{(i)}\;\; \text{the population standard deviation } \sigma \text{ is known} \qquad \textbf{(ii)}\;\; n \ge 30(i)the population standard deviation σ is known(ii)n≥30

If σ\sigmaσ is unknown, you estimate it from the sample and switch to the t-test. The formula is the standardization you already met with z-scores — but applied to the sample mean, whose spread is the standard error σ/n\sigma/\sqrt{n}σ/n​:

zscore=X−μσ,zd=xˉ−μσ/nz_{\text{score}} = \frac{X - \mu}{\sigma}, \qquad\qquad z_{d} = \frac{\bar{x} - \mu}{\sigma/\sqrt{n}}zscore​=σX−μ​,zd​=σ/n​xˉ−μ​

The right-hand formula — the test statistic — measures how many standard errors the sample mean xˉ\bar xxˉ sits from the claimed mean μ\muμ.

Example 1 — a two-tailed height test​

The average height of all residents in a city is 168 cm, with σ = 3.9. A doctor believes the mean to be different. He measures the height of 36 individuals and finds the average height to be 169.5 cm. (a) State the null and alternate hypotheses. (b) At a 95% confidence level, is there enough evidence to reject the null?

Given:

μ=168,σ=3.9,n=36,xˉ=169.5,C.I.=0.95,α=1−C.I.=0.05\mu = 168, \quad \sigma = 3.9, \quad n = 36, \quad \bar x = 169.5, \quad \text{C.I.} = 0.95, \quad \alpha = 1 - \text{C.I.} = 0.05μ=168,σ=3.9,n=36,xˉ=169.5,C.I.=0.95,α=1−C.I.=0.05

① Null hypothesis H0: μ=168H_0:\ \mu = 168H0​: μ=168 cm. ② Alternate hypothesis H1: μ≠168H_1:\ \mu \neq 168H1​: μ=168 cm — "different" in either direction, so this is a two-tailed test.

③ Decision boundary from the C.I. A two-tailed 95% leaves 2.5% in each tail. The critical z comes from the z-table: the area to the left of the upper cutoff is 1−0.025=0.97501 - 0.025 = 0.97501−0.025=0.9750, which maps to a z-score of +1.96. So the rule is:

if z<−1.96  or  z>+1.96, reject H0.\text{if } z < -1.96 \ \text{ or } \ z > +1.96, \ \textbf{reject } H_0.if z<−1.96  or  z>+1.96, reject H0​.

Compute the test statistic:

zd=xˉ−μσ/n=169.5−1683.9/36=1.50.65=2.31z_d = \frac{\bar x - \mu}{\sigma/\sqrt n} = \frac{169.5 - 168}{3.9/\sqrt{36}} = \frac{1.5}{0.65} = \boxed{2.31}zd​=σ/n​xˉ−μ​=3.9/36​169.5−168​=0.651.5​=2.31​

Since 2.31>1.962.31 > 1.962.31>1.96, the statistic lands in the right rejection region. Equivalently, the two-tailed p-value is the area in both tails beyond ±2.31\pm 2.31±2.31:

p=0.01044+0.01044=0.02088,0.02088<0.05 ⇒ reject H0.p = 0.01044 + 0.01044 = 0.02088, \qquad 0.02088 < 0.05 \ \Rightarrow\ \textbf{reject } H_0.p=0.01044+0.01044=0.02088,0.02088<0.05 ⇒ reject H0​.

The rejection region is fixed by α before you see data. If the observed statistic lands in it — equivalently, once its p-value (yellow) is smaller than α (red) — you reject H₀. Switch to t and drag df down: the tails fatten, the critical value moves outward, and small samples get harder to call.

Final conclusion: the average height ≠168\neq 168=168 cm. Based on this sample, the average height seems to be increasing.

Example 2 — a one-tailed warranty test​

A factory manufactures bulbs with an average warranty of 5 years, standard deviation 0.50. A worker believes the bulbs malfunction in less than 5 years. He tests 40 bulbs and finds the average life to be 4.8 years. (a) State the hypotheses. (b) At a 2% significance level, is there enough evidence that the warranty should be revised?

Given: μ=5, σ=0.50, n=40, xˉ=4.8, α=0.02\mu = 5,\ \sigma = 0.50,\ n = 40,\ \bar x = 4.8,\ \alpha = 0.02μ=5, σ=0.50, n=40, xˉ=4.8, α=0.02.

① Null H0: μ=5H_0:\ \mu = 5H0​: μ=5. ② Alternate H1: μ<5H_1:\ \mu < 5H1​: μ<5 — "less than" points one way, so this is a one-tailed (left) test. All 2% of the rejection area sits in the left tail; the other 98% is the acceptance region.

Test statistic:

zd=xˉ−μσ/n=4.8−50.50/40=−2.53z_d = \frac{\bar x - \mu}{\sigma/\sqrt n} = \frac{4.8 - 5}{0.50/\sqrt{40}} = -2.53zd​=σ/n​xˉ−μ​=0.50/40​4.8−5​=−2.53

The area under the curve beyond z=−2.53z = -2.53z=−2.53 is the p-value =0.0570= 0.0570=0.0570. Now compare it with α\alphaα:

p<α ?0.0570<0.02 ⇒ Falsep < \alpha \ ? \quad 0.0570 < 0.02 \ \Rightarrow\ \textbf{False}p<α ?0.0570<0.02 ⇒ False

The rejection region is fixed by α before you see data. If the observed statistic lands in it — equivalently, once its p-value (yellow) is smaller than α (red) — you reject H₀. Switch to t and drag df down: the tails fatten, the critical value moves outward, and small samples get harder to call.

Because the p-value is not below α\alphaα, we accept (fail to reject) the null hypothesis — there isn't enough evidence at the 2% level to say the true warranty is under 5 years. Notice the same z=−2.53z=-2.53z=−2.53 would have been significant at α=0.05\alpha=0.05α=0.05; the stricter 2% bar changed the verdict. The threshold is part of the result.

import numpy as np
from scipy import stats

def z_test(xbar, mu0, sigma, n, alpha, tail):
    z = (xbar - mu0) / (sigma / np.sqrt(n))
    if tail == 'two':
        p = 2 * (1 - stats.norm.cdf(abs(z)))
    elif tail == 'left':
        p = stats.norm.cdf(z)
    else:  # right
        p = 1 - stats.norm.cdf(z)
    verdict = "REJECT H0" if p < alpha else "fail to reject H0"
    print(f"z = {z:.2f},  p = {p:.4f},  α = {alpha}  ->  {verdict}")

# Example 1: two-tailed height test
z_test(xbar=169.5, mu0=168, sigma=3.9, n=36, alpha=0.05, tail='two')
# Example 2: one-tailed (left) bulb-warranty test
z_test(xbar=4.8,   mu0=5,   sigma=0.50, n=40, alpha=0.02, tail='left')

Why a quant cares​

The z-test is the skeleton under a lot of trading statistics, and its conditions are exactly where people cheat:

  • "Is this month's average return different from zero?" is a z-test on xˉ\bar xxˉ with test statistic xˉ/(σ/n)\bar x/(\sigma/\sqrt n)xˉ/(σ/n​) — which, annualized, is essentially the Sharpe ratio times n\sqrt{n}n​. Testing an edge and computing a Sharpe are the same calculation.
  • The one-vs-two-tail choice is a modeling decision with teeth. "Is there any edge?" is two-tailed; "is the edge positive?" is one-tailed and easier to clear — which is why a one-tailed test on a strategy you already believe in quietly doubles your false-positive rate.
  • σ is almost never actually known in markets, and volatility isn't even constant — so the honest tool is usually the t-test, with the z-test as the large-sample limit.
