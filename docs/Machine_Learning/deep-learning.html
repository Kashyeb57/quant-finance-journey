Neural Networks & Deep Learning

Neural networks stack simple units into a machine that can approximate almost any function. For tabular finance data, tree ensembles usually win — but for images, audio, text, and sequences (like price series), deep learning is the tool. This page builds the intuition from one neuron up to CNNs and RNNs.

The artificial neuron​

A single neuron does two things: take a weighted sum of its inputs plus a bias, then pass it through a non-linear activation:

a=ϕ(w⋅x+b)a = \phi\big(\mathbf{w}\cdot\mathbf{x} + b\big)a=ϕ(w⋅x+b)

That's the same w⋅x+b\mathbf{w}\cdot\mathbf{x}+bw⋅x+b hyperplane from Foundations, wrapped in a squashing function. Stack neurons into layers, and layers into a network — input layer → hidden layers → output layer — where each layer transforms the previous one's output. Data flowing input-to-output is the forward pass:

import numpy as np
def relu(z): return np.maximum(0, z)

x  = np.array([0.5, -1.2, 2.0])                 # 3 inputs
W1 = np.array([[ 0.2, 0.8, -0.5],               # hidden layer: 2 neurons, each with 3 weights
               [-0.3, 0.1,  0.9]])
b1 = np.array([0.1, -0.2])

h = relu(W1 @ x + b1)                            # weighted sum -> activation
print("hidden-layer activations:", np.round(h, 3))

The depth (many hidden layers) is what "deep" means, and it lets the network learn hierarchical features — early layers catch simple patterns, later layers combine them into complex ones.

Activation functions — where the power comes from​

Without a non-linear activation, stacking layers collapses to a single linear model (a line composed with a line is still a line). The activation is what lets networks bend:

  • Sigmoid — squashes to (0,1)(0,1)(0,1); historically popular but saturates (gradients vanish at the extremes).
  • Tanh — like sigmoid but (−1,1)(-1,1)(−1,1) and zero-centered; still saturates.
  • ReLU — max⁡(0,z)\max(0, z)max(0,z). Cheap, doesn't saturate for positive values, and is the default hidden-layer activation in modern nets. (Variants like Leaky ReLU fix its "dying" zero region.)
  • Softmax — the output activation for multi-class classification; turns raw scores into probabilities that sum to 1.

How a network learns​

  1. Loss function — measure how wrong the output is. MSE for regression, cross-entropy for classification (same choices as regression & classification).
  2. Backpropagation — the chain rule, applied efficiently, to compute the gradient of the loss with respect to every weight in the network.
  3. Gradient descent — nudge each weight a little in the direction that reduces the loss. Repeat over many passes (epochs) through the data.

That loop — forward pass → loss → backprop → update — is all of deep learning, run millions of times.

Optimizers: how you take the step​

Plain gradient descent works but is slow and fiddly. Optimizers improve how the weights update:

  • SGD — update on small mini-batches instead of the whole dataset (faster, noisier, often generalizes better).
  • Momentum — accumulate a velocity so updates keep rolling through flat spots and small bumps.
  • RMSProp — scale each weight's step by its recent gradient size (adaptive per-parameter learning rate).
  • Adam — momentum + RMSProp combined; the robust default first choice.

The learning rate is the single most important knob: too high and training diverges, too low and it crawls.

Weight initialization​

You can't start all weights at zero (every neuron would learn the same thing) or too large (activations explode). Schemes like Xavier/Glorot (for tanh/sigmoid) and He (for ReLU) set the initial scale so signals and gradients stay healthy through deep networks — a small detail that decides whether a net trains or stalls.

A network in action​

MLPClassifier is a full feed-forward net. Watch it crush a problem a linear model can't touch — the interleaving crescents:

import numpy as np
from sklearn.neural_network import MLPClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import make_moons
from sklearn.model_selection import cross_val_score

X, y = make_moons(n_samples=500, noise=0.2, random_state=0)

print("logistic (linear) CV accuracy:", round(cross_val_score(LogisticRegression(), X, y, cv=5).mean(), 3))
mlp = MLPClassifier(hidden_layer_sizes=(16, 16), max_iter=2000, random_state=0)
print("neural network    CV accuracy:", round(cross_val_score(mlp, X, y, cv=5).mean(), 3))
runs in your browser

Two 16-neuron hidden layers learn the curved boundary the straight line never could — that's the non-linearity from ReLU at work.

In quant terms — point that same net at lagged returns to predict next-day direction, but judge it the honest way (walk-forward), and it tells the sobering truth:

import numpy as np
from sklearn.neural_network import MLPClassifier
from sklearn.model_selection import TimeSeriesSplit, cross_val_score

rng = np.random.default_rng(5)
n = 1500
z = rng.normal(0, 1, n)
ret = 0.1 * np.r_[0, z[:-1]] + z                     # a faint real signal buried in noise
X = np.column_stack([np.r_[np.zeros(k), ret[:-k]] for k in (1, 2, 3, 5)])[6:]
y = (ret[6:] > 0).astype(int)

mlp = MLPClassifier(hidden_layer_sizes=(32, 16), max_iter=1500, random_state=0)
acc = cross_val_score(mlp, X, y, cv=TimeSeriesSplit(5)).mean()
print(f"MLP walk-forward accuracy on next-day direction: {acc:.3f}")
print("(barely above 0.5 — a deep net can't conjure signal out of noise)")
runs in your browser

That result is the whole point: a network with thousands of parameters still can't beat chance on a near-random return series. On markets, capacity without signal just means faster overfitting — which is exactly why the caution below matters.

Specialized architectures​

  • CNN (Convolutional Neural Network) — for grid data (images). Instead of connecting every pixel to every neuron, convolution slides small learnable filters across the input to detect local patterns (edges → shapes → objects), and pooling downsamples. Far fewer parameters, and translation-invariant.
  • RNN / LSTM / GRU — for sequences, where order matters — natural for time series and text. They carry a hidden "memory" across steps; LSTMs/GRUs add gates so they remember long-range dependencies without the gradients vanishing.
  • Transformers — the attention-based architecture behind modern LLMs; now dominant for text and increasingly for sequences.

Deep learning in quant — with caution​

DL shines in finance on sequence and alternative data: LSTMs/transformers on price and order-flow series, CNNs on limit-order-book "images," transformers on news text. But two warnings loom larger here than anywhere:

  • Data hunger vs. scarcity. Deep nets need a lot of data; financial history is short and non-stationary, so they overfit easily. Often a regularized linear model or gradient boosting beats a neural net on tabular signals.
  • Evaluation discipline. Everything in Model Evaluation applies double — walk-forward validation, no leakage, and deep suspicion of a backtest that looks too good.
