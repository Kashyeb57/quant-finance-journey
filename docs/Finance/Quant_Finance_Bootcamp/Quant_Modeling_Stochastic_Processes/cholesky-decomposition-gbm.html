Cholesky Decomposition for Geometric Brownian Motion (GBM)

Correlated processes​

GBM → model a single stock. Now consider two stocks:

  • S₁ → ABC.
  • S₂ → XYZ.

The example labels both as financial companies and asks whether S₁ and S₂ will have correlation or not: yes.

When we model our stocks using geometric Brownian motion, we need to make sure that the same correlation is also integrated within the GBM process. The diagram shows S₁ and S₂ linked by correlation before modeling, each passing through a GBM arrow, with correlation retained between the two resulting processes.

To integrate the correlation between the processes, we use Cholesky decomposition.

Cholesky decomposition​

Step 1: define the correlation matrix​

The example's correlation between S₁ and S₂ is ρ = 0.6 or 60%.

Σ=[1ρρ1].\Sigma=\begin{bmatrix}1&\rho\\\rho&1\end{bmatrix}.Σ=[1ρ​ρ1​].

Note:

−1≤ρ≤1.-1\leq\rho\leq1.−1≤ρ≤1.

Step 2: define Cholesky decomposition​

The goal is to find a lower triangular matrix such that:

L=[L110L21L22],LT=[L11L210L22],L=\begin{bmatrix}L_{11}&0\\L_{21}&L_{22}\end{bmatrix}, \qquad L^T=\begin{bmatrix}L_{11}&L_{21}\\0&L_{22}\end{bmatrix},L=[L11​L21​​0L22​​],LT=[L11​0​L21​L22​​], Σ=LLT.\boxed{\Sigma=LL^T}.Σ=LLT​.

The superscript T marks the transpose; Σ is the correlation matrix.

Matrix multiplication​

[1ρρ1]=[L110L21L22][L11L210L22].\begin{bmatrix}1&\rho\\\rho&1\end{bmatrix} =\begin{bmatrix}L_{11}&0\\L_{21}&L_{22}\end{bmatrix} \begin{bmatrix}L_{11}&L_{21}\\0&L_{22}\end{bmatrix}.[1ρ​ρ1​]=[L11​L21​​0L22​​][L11​0​L21​L22​​].

From the upper-left entry:

L11⋅L11=1,L112=1,L11=1.L_{11}\cdot L_{11}=1, \qquad L_{11}^2=1, \qquad\boxed{L_{11}=1}.L11​⋅L11​=1,L112​=1,L11​=1​.

From the upper-right entry:

L11L21+0⋅L22=ρ.L_{11}L_{21}+0\cdot L_{22}=\rho.L11​L21​+0⋅L22​=ρ. L11L21=ρ.L_{11}L_{21}=\rho.L11​L21​=ρ.

Since L₁₁ = 1:

L21=ρ.\boxed{L_{21}=\rho}.L21​=ρ​.

From the lower-right entry:

1=L212+L222.1=L_{21}^2+L_{22}^2.1=L212​+L222​. 1=ρ2+L222.1=\rho^2+L_{22}^2.1=ρ2+L222​. L22=1−ρ2.\boxed{L_{22}=\sqrt{1-\rho^2}}.L22​=1−ρ2​​.

Therefore the Cholesky matrix is:

L=[L110L21L22]=[10ρ1−ρ2].L=\begin{bmatrix}L_{11}&0\\L_{21}&L_{22}\end{bmatrix} =\boxed{\begin{bmatrix}1&0\\\rho&\sqrt{1-\rho^2}\end{bmatrix}}.L=[L11​L21​​0L22​​]=[1ρ​01−ρ2​​]​.

Use Cholesky decomposition in GBM​

Let's assume we have 2 correlated stocks.

Step 1: GBM equation​

For a single stock:

dSt=μSt dt+σSt dWt.dS_t=\mu S_t\,dt+\sigma S_t\,dW_t.dSt​=μSt​dt+σSt​dWt​.
  • Sₜ: stock price at time t.
  • μ: expected return.
  • σ: volatility.
  • dWₜ: Wiener process, the random component.

Step 2: correlating our Wiener processes using Cholesky decomposition​

The diagram connects S₁, S₂ → ρ → dW₁, dW₂, asks “How?”, and points to Cholesky decomposition. It recalls dW₁ = Z₁ sqrt(t) for an increment over a time interval.

a) Generate standard normal random variables Z₁, Z₂.

For each stock, the Excel draw is:

=NORM.S.INV(RAND())

S₁ → Z₁, S₂ → Z₂.

b) Use Cholesky decomposition to transform these independent random variables to correlated random variables.

The two-column sketch labels the original Z₁/Z₂ columns uncorrelated and the transformed Z₁′/Z₂′ columns correlated random variables, with ρ beside the transformation arrow.

L=[10ρ1−ρ2],LLT=Σ.L=\begin{bmatrix}1&0\\\rho&\sqrt{1-\rho^2}\end{bmatrix}, \qquad LL^T=\Sigma.L=[1ρ​01−ρ2​​],LLT=Σ.

Calculate correlated Wiener processes​

Using the source's primed dW notation:

[dW1′dW2′]=L[Z1Z2]=[10ρ1−ρ2][Z1Z2].\begin{bmatrix}dW_1'\\dW_2'\end{bmatrix} =L\begin{bmatrix}Z_1\\Z_2\end{bmatrix} =\begin{bmatrix}1&0\\\rho&\sqrt{1-\rho^2}\end{bmatrix} \begin{bmatrix}Z_1\\Z_2\end{bmatrix}.[dW1′​dW2′​​]=L[Z1​Z2​​]=[1ρ​01−ρ2​​][Z1​Z2​​].

The uncorrelated dW₁/dW₂ are associated with Z₁/Z₂; multiplying by L gives the correlated pair. The matrix multiplication gives:

dW1′=1⋅Z1+0⋅Z2,dW1′=Z1.dW_1'=1\cdot Z_1+0\cdot Z_2, \qquad\boxed{dW_1'=Z_1}.dW1′​=1⋅Z1​+0⋅Z2​,dW1′​=Z1​​.

This is labelled correlated Wiener process for S₁.

dW2′=ρZ1+1−ρ2 Z2.\boxed{dW_2'=\rho Z_1+\sqrt{1-\rho^2}\,Z_2}.dW2′​=ρZ1​+1−ρ2​Z2​​.

This is labelled correlated Wiener process for S₂. The paired-column sketch repeats Z₁ in the first transformed column and ρZ₁ + √(1−ρ²)Z₂ in the second.

Step 3: simulate GBM for correlated stocks​

The handwritten equations are:

St+Δt1=St1exp⁡[(μ1−0.5σ12)Δt+σ1dW1′],S_{t+\Delta t}^{1}=S_t^{1} \exp\left[(\mu_1-0.5\sigma_1^2)\Delta t+\sigma_1dW_1'\right],St+Δt1​=St1​exp[(μ1​−0.5σ12​)Δt+σ1​dW1′​], St+Δt2=St2exp⁡[(μ2−0.5σ22)Δt+σ2dW2′].S_{t+\Delta t}^{2}=S_t^{2} \exp\left[(\mu_2-0.5\sigma_2^2)\Delta t+\sigma_2dW_2'\right].St+Δt2​=St2​exp[(μ2​−0.5σ22​)Δt+σ2​dW2′​].
Time-step scaling

The transformed variables LZ above are correlated standard-normal draws. Actual Wiener increments over Δt are √Δt LZ. The source uses dW′ for both the draws and the increments. Its Excel stock formulas supply the required √Δt multiplier explicitly, as shown below.

Conclusion in the notes​

The final diagram is dW₁, dW₂ → dW₁′, dW₂′ → correlated Wiener process → ρ → S₁, S₂. The concluding equations repeat:

Σ=[1ρρ1],LLT=Σ,[dW1′dW2′]=L[Z1Z2],\Sigma=\begin{bmatrix}1&\rho\\\rho&1\end{bmatrix}, \qquad LL^T=\Sigma, \qquad \begin{bmatrix}dW_1'\\dW_2'\end{bmatrix} =L\begin{bmatrix}Z_1\\Z_2\end{bmatrix},Σ=[1ρ​ρ1​],LLT=Σ,[dW1′​dW2′​​]=L[Z1​Z2​​], dW1′=Z1,dW2′=ρZ1+1−ρ2 Z2.\boxed{dW_1'=Z_1,\qquad dW_2'=\rho Z_1+\sqrt{1-\rho^2}\,Z_2}.dW1′​=Z1​,dW2′​=ρZ1​+1−ρ2​Z2​​.

The source sheet resets its stock prices each row

The copied M/N formulas retain BBB8 / BBB9, the initial stock prices, on every row. For example, M3 still starts from BBB8, not M2. The sheet therefore contains 252 correlated one-step draws from the starting prices, rather than one cumulative 252-step GBM path. For a cumulative path, later rows must use the preceding row's stock prices — M3 should start from M2. The formulas above reproduce the source sheet exactly, including this quirk; note that the GBM sheet in the same workbook does compound correctly (L3 = L2*EXP(...)), so the two sheets disagree.
