Types of Probability Distribution

A dataset becomes a distribution. Collect enough ages, weights, or salaries and each column stops being a list of numbers and starts having a shape — some pile up in a symmetric hump, some lean right, some sit flat. Each recognizable shape has a name, a formula (a PMF or PDF), and a set of assumptions. This page is the map; the rest of the module is the territory.

The six named distributions in this module​

Each row is a lesson. The key split is the one from the last page: discrete → PMF, continuous → PDF.

#DistributionTypeDiscrete/ContinuousModels
1BernoulliPMFDiscreteone yes/no trial — a binary outcome
2BinomialPMFDiscretenumber of successes in nnn trials
3PoissonPMFDiscretenumber of events in a fixed interval
4Normal / GaussianPDFContinuousthe symmetric bell — the default "assumption"
5Log-NormalPDFContinuousright-skewed, positive-only (prices, incomes)
6UniformPMF or PDFEitherevery outcome equally likely (flat)
  • Bernoulli — outcomes are binary (success/failure). Discrete.
  • Binomial — repeat a Bernoulli trial nnn times and count the successes. Discrete.
  • Normal/Gaussian — the symmetric bell curve; the distribution most models assume. Continuous.
  • Poisson — counts of events in a window (arrivals per hour). Discrete.
  • Log-Normal — a right-skewed hump for quantities that can't go negative. Continuous.
  • Uniform — a flat distribution where everything is equally likely; discrete (a die, a PMF) or continuous (a random point in an interval, a PDF).

Two more, beyond the six, matter enormously in finance and get their own lessons in module 4: the Power Law and the Pareto distribution — the heavy-tailed shapes that the tidy list above quietly ignores.

One dataset, many distributions​

A real dataset almost never has one distribution — each column picks its own. The lecture's example is a house-price prediction dataset, the kind a data analyst or data scientist explores (EDA) and engineers features from (FE). Walk the columns:

FeatureValuesRandom variableFunction
Size of the houseany positive number (sq ft)ContinuousPDF
Number of rooms1,2,3,…1, 2, 3, \dots1,2,3,… (counts)DiscretePMF
Floor1,2,3,…1, 2, 3, \dots1,2,3,… (counts)DiscretePMF

LocationcategoriesDiscrete (categorical)PMF
Price (the target)any positive number ($)ContinuousPDF

The "sea-side view" column — a plain {0,1}\{0,1\}{0,1} flag — is a Bernoulli variable, whether or not anyone labels it that way. Recognizing which distribution each feature follows is exactly what tells you how to scale it, which model can consume it, and what a "surprising" value would even mean.

import pandas as pd

house = pd.DataFrame({
    "size_sqft":  [900, 1200, 1500, 2000, 850],   # continuous  -> PDF
    "rooms":      [2, 3, 3, 4, 1],                 # discrete    -> PMF
    "floor":      [1, 5, 2, 12, 1],                # discrete    -> PMF
    "sea_view":   [0, 0, 1, 1, 0],                 # Bernoulli   -> PMF
    "price_k":    [120, 180, 260, 540, 95],        # continuous  -> PDF (the target)
})

for col in house.columns:
    kind = "discrete (PMF)" if house[col].nunique() <= 6 and (house[col] % 1 == 0).all() else "continuous (PDF)"
    print(f"{col:10s} -> {kind}")

Why a quant cares​

Choosing a distribution is a modeling decision, and every one carries assumptions that can quietly break:

  • Model a stock price as Normal and you allow negative prices — impossible. That's why prices are modeled Log-Normal (positive-only, right-skewed).
  • Model daily returns as Normal and you assume thin tails — but real returns have fat tails (power law territory), so a "Normal" risk model badly understates crashes.
  • Model defaults or trade arrivals as independent counts and you're in Binomial / Poisson land — useful, until the independence assumption fails.

The whole skill is matching the shape of the data to the distribution whose assumptions actually hold. Start with the simplest discrete one: the Bernoulli trial.
