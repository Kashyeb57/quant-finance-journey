Poisson Distribution

The Poisson distribution is a discrete probability distribution that expresses the probability of a given number of events occurring in a fixed interval of time — provided those events occur with a known constant mean rate and independently of the time since the last event.

Its two defining features:

  1. It's a discrete random variable (a PMF).
  2. It describes the number of events occurring in a fixed time interval.

Examples: the number of people visiting a hospital every hour; the number of people visiting a bank every hour. The count is a whole number — 0, 1, 2, … — and it fluctuates around some average rate.

The rate parameter λ​

The single parameter is λ\lambdaλ (lambda), the expected number of events per interval. If a bank sees on average λ=3\lambda = 3λ=3 customers per hour, then across the afternoon — 12pm, 1pm, 2pm, 3pm, 4pm, 5pm — each hour brings a random count that averages 3 but might be 1, or 4, or 6:

λ=3  ⇒  expected number of events occurring in each time interval\lambda = 3 \;\Rightarrow\; \text{expected number of events occurring in each time interval}λ=3⇒expected number of events occurring in each time interval

The PMF​

P(X=x)=e−λ λxx!,x=0,1,2,…P(X = x) = \frac{e^{-\lambda}\, \lambda^{x}}{x!}, \qquad x = 0, 1, 2, \dotsP(X=x)=x!e−λλx​,x=0,1,2,…

It's defined only at integer xxx (you can't have 2.5 arrivals). With λ=3\lambda = 3λ=3, the probability of exactly 5 customers in an hour is:

P(X=5)=e−3 355!=0.0498×243120=0.101=10.1%P(X = 5) = \frac{e^{-3}\, 3^{5}}{5!} = \frac{0.0498 \times 243}{120} = 0.101 = 10.1\%P(X=5)=5!e−335​=1200.0498×243​=0.101=10.1%

And because it's a proper distribution you can accumulate it — e.g. P(X≤3)=P(0)+P(1)+P(2)+P(3)P(X \le 3) = P(0)+P(1)+P(2)+P(3)P(X≤3)=P(0)+P(1)+P(2)+P(3), or combine pieces like P(X=4)+P(X=5)P(X=4) + P(X=5)P(X=4)+P(X=5) for "4 or 5 arrivals." Mean and variance — the signature property​

Mean=E[X]=μ=λ×t,Variance=λ×t\text{Mean} = E[X] = \mu = \lambda \times t, \qquad \text{Variance} = \lambda \times tMean=E[X]=μ=λ×t,Variance=λ×t

where λ\lambdaλ is the expected number of events per unit time and ttt is the length of the interval. For a single unit interval this is just μ=λ\mu = \lambdaμ=λ. The striking part is that the mean and the variance are the same number — the arrow in the notes points from mean straight to variance because they're equal:

  mean=variance=λ  \boxed{\;\text{mean} = \text{variance} = \lambda\;}mean=variance=λ​

This equidispersion is the Poisson's fingerprint. If you measure counts and find the variance roughly equals the mean, Poisson is a good model; if the variance is much bigger (overdispersion), the events are clustering and you need something else.

Poisson in 3D — how λ reshapes the counts​

Let the rate λ\lambdaλ climb and watch the PMF over (λ,k)(\lambda, k)(λ,k). At small λ\lambdaλ the mass sits near 0 and is lopsided; as λ\lambdaλ grows the hump slides right (peak near k=λk = \lambdak=λ), widens, and turns symmetric and bell-like — for large λ\lambdaλ the Poisson is well approximated by a Normal. Drag to rotate:

3DPoisson PMF as the rate λ grows

Each slice at a fixed λ is one Poisson PMF. Small λ → skewed, piled near zero; large λ → a symmetric bell centered on λ, with spread √λ.

from math import exp, factorial

def poisson_pmf(x, lam):
    return exp(-lam) * lam**x / factorial(x)

# λ = 3: probability of exactly 5 events
print("P(X=5 | λ=3) =", round(poisson_pmf(5, 3), 4))          # 0.1008 ≈ 10.1%

# P(X ≤ 3)
print("P(X<=3 | λ=3) =", round(sum(poisson_pmf(k, 3) for k in range(4)), 4))

# mean = variance = λ  — confirm by simulation
import numpy as np
sample = np.random.default_rng(0).poisson(lam=3, size=100_000)
print(f"simulated mean = {sample.mean():.3f},  variance = {sample.var():.3f}  (both ≈ λ = 3)")

Why a quant cares​

The Poisson is the model for rare, countable events arriving over time — which is most of market microstructure and risk:

  • Order and trade arrivals. The number of trades in a second, or market-orders hitting your quote, is classically Poisson — the backbone of queueing models in high-frequency trading.
  • Jumps. In a jump-diffusion model of prices, the number of sudden jumps in an interval is Poisson; it's how you bolt crash-risk onto an otherwise smooth model.
  • Operational and credit events. Rare losses, fraud events, or defaults in a large pool with small individual probability converge to Poisson (the "law of rare events": a Binomial with large nnn and small ppp becomes Poisson with λ=np\lambda = npλ=np).

The equidispersion assumption is the thing to test: real trade counts often cluster (bursts of activity), giving variance well above the mean — a signal that arrivals aren't independent and a plain Poisson understates the busy-period risk.
