Chapter 4: Applications of Differentiation

4.1 Maximum and Minimum Values​

Extrema of a function on [a, b]

Finding extrema:

  1. Extreme Value Theorem: If fff is continuous on [a,b][a,b][a,b], then fff attains both an absolute maximum and absolute minimum.
  2. Critical numbers: f′(c)=0f'(c) = 0f′(c)=0 OR f′(c)f'(c)f′(c) is undefined.
  3. Check: Evaluate fff at critical points + endpoints to find the absolute extrema.

4.2 The Mean Value Theorem​

Rolle's Theorem: If f(a)=f(b)f(a) = f(b)f(a)=f(b) and fff is continuous on [a,b][a,b][a,b] and differentiable on (a,b)(a,b)(a,b), then ∃ c∈(a,b)\exists\, c \in (a,b)∃c∈(a,b) where f′(c)=0f'(c) = 0f′(c)=0.

Rolle's Theorem

Mean Value Theorem (MVT): ∃ c∈(a,b)\exists\, c \in (a,b)∃c∈(a,b) where

f′(c)=f(b)−f(a)b−af'(c) = \frac{f(b) - f(a)}{b - a}f′(c)=b−af(b)−f(a)​

The tangent at ccc is parallel to the secant line joining (a,f(a))\bigl(a, f(a)\bigr)(a,f(a)) and (b,f(b))\bigl(b, f(b)\bigr)(b,f(b)) — its slope equals the average rate of change.

4.3 How Derivatives Affect Graph Shape​

  • f′(x)>0  ⟹  ff'(x) > 0 \implies ff′(x)>0⟹f is INCREASING ↗

  • f′(x)<0  ⟹  ff'(x) < 0 \implies ff′(x)<0⟹f is DECREASING ↘

  • f′(x)=0  ⟹  ff'(x) = 0 \implies ff′(x)=0⟹f has a horizontal tangent (potential extremum)

  • f′′(x)>0  ⟹  ff''(x) > 0 \implies ff′′(x)>0⟹f is CONCAVE UP ∪

  • f′′(x)<0  ⟹  ff''(x) < 0 \implies ff′′(x)<0⟹f is CONCAVE DOWN ∩

  • f′′(x)=0  ⟹  f''(x) = 0 \impliesf′′(x)=0⟹ possible INFLECTION POINT

Full picture — a curve carrying a local max, a local min, and an inflection point where concavity flips:

How f' and f'' shape the graph
f'>0 rising ↗, f'<0 falling ↘; f''>0 concave up ∪, f''<0 concave down ∩

Second Derivative Test: At critical point ccc where f′(c)=0f'(c) = 0f′(c)=0:

  • f′′(c)>0  ⟹  f''(c) > 0 \impliesf′′(c)>0⟹ local MINIMUM (concave up = bowl) ∪
  • f′′(c)<0  ⟹  f''(c) < 0 \impliesf′′(c)<0⟹ local MAXIMUM (concave down = hill) ∩
  • f′′(c)=0  ⟹  f''(c) = 0 \impliesf′′(c)=0⟹ test inconclusive (need more analysis)

4.5 Curve Sketching Checklist​

STEP-BY-STEP:

  1. Domain: Where is fff defined?
  2. Intercepts: Set f=0f=0f=0 (x-int), x=0x=0x=0 (y-int)
  3. Symmetry: Even? f(−x)=f(x)f(-x)=f(x)f(−x)=f(x) Odd? f(−x)=−f(x)f(-x)=-f(x)f(−x)=−f(x)
  4. Asymptotes: Vertical (where f→∞f \to \inftyf→∞), Horizontal (limits at ±∞\pm \infty±∞)
  5. Increase/Dec: Sign of f′f'f′
  6. Local Extrema: f′=0f'=0f′=0 and sign change
  7. Concavity: Sign of f′′f''f′′
  8. Inflection pts: f′′f''f′′ changes sign
  9. Sketch!

4.7 Optimization Problems​

STRATEGY:

  1. Read carefully — what to maximize/minimize?
  2. Draw a diagram
  3. Label variables, write constraint equation
  4. Write objective function in ONE variable
  5. Find critical points (set derivative = 000)
  6. Verify it's max/min (2nd derivative test or interval check)

CLASSIC EXAMPLE: Maximize area of rectangle with perimeter = 40.

P=2x+2y=40  ⟹  y=20−xA=xy=x(20−x)=20x−x2A′=20−2x=0  ⟹  x=10,y=10\begin{aligned} P &= 2x + 2y = 40 \implies y = 20 - x \\ A &= xy = x(20 - x) = 20x - x^2 \\ A' &= 20 - 2x = 0 \implies x = 10, y = 10 \end{aligned}PAA′​=2x+2y=40⟹y=20−x=xy=x(20−x)=20x−x2=20−2x=0⟹x=10,y=10​

A square maximizes the area!
