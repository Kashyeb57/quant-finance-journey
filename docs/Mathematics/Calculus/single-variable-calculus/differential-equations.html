Chapter 9: Differential Equations

9.1 What is a Differential Equation?​

An equation involving a function AND its derivatives.

ORDER = highest derivative present.

Examples:

  • y′=kyy' = kyy′=ky (1st order — population growth)
  • y′′+ω2y=0y'' + \omega^2y = 0y′′+ω2y=0 (2nd order — oscillation)
  • ∂u∂t=k∂2u∂x2\frac{\partial u}{\partial t} = k \frac{\partial^2 u}{\partial x^2}∂t∂u​=k∂x2∂2u​ (PDE — heat equation)

9.2 Direction Fields and Euler's Method​

Direction Field: At each point (x,y), draw a short line with slope f'=F(x,y).

Example: y′=yy' = yy′=y (solution is exe^xex)

Direction Field & Solution Curve
Arrows show direction (slope = y). Solution curves follow the arrows.

Euler's Method — numerical approximation:

yn+1=yn+h⋅F(xn,yn)y_{n+1} = y_n + h \cdot F(x_n, y_n)yn+1​=yn​+h⋅F(xn​,yn​)

Start at (x0,y0)(x_0, y_0)(x0​,y0​) and take steps of size hhh. Each step follows the local tangent slope, so the straight-line Euler path drifts below the true (curving) solution — error grows with each step.

Euler's method vs. the exact solution
The straight Euler segments fall below the curving true solution — error grows.

Form: dydx=g(x)⋅h(y)\frac{dy}{dx} = g(x) \cdot h(y)dxdy​=g(x)⋅h(y)

Separate variables:

1h(y) dy=g(x) dx\frac{1}{h(y)} \, dy = g(x) \, dxh(y)1​dy=g(x)dx

9.4 Logistic Growth​

dPdt=kP(1−PM),P(t)=M1+A e−kt\frac{dP}{dt} = kP\left(1 - \frac{P}{M}\right), \qquad P(t) = \frac{M}{1 + A\,e^{-kt}}dtdP​=kP(1−MP​),P(t)=1+Ae−ktM​

where MMM is the carrying capacity (maximum sustainable population). Growth is fastest at the inflection point P=M/2P = M/2P=M/2 and slows to zero as PPP approaches the asymptote MMM.

Logistic growth — the S-curve
Growth slows as the population approaches the carrying capacity M.

Quant Finance: Logistic model for market saturation, adoption curves.

9.5 First-Order Linear ODEs​

Form: y′+P(x)y=Q(x)y' + P(x)y = Q(x)y′+P(x)y=Q(x)

SOLUTION METHOD — Integrating Factor:

I(x)=e∫P(x)dxI(x) = e^{\int P(x) dx}I(x)=e∫P(x)dx

Multiply both sides by I(x)I(x)I(x):

[I(x)⋅y]′=I(x)⋅Q(x)[I(x) \cdot y]' = I(x) \cdot Q(x)[I(x)⋅y]′=I(x)⋅Q(x)

Integrate both sides:

I(x)⋅y=∫I(x)⋅Q(x) dxI(x) \cdot y = \int I(x) \cdot Q(x) \, dxI(x)⋅y=∫I(x)⋅Q(x)dx

dxdt=ax−bxy(prey — grows alone, dies with predator)dydt=−cy+dxy(predator — dies alone, grows with prey)\begin{aligned} \frac{dx}{dt} &= ax - bxy && \text{(prey — grows alone, dies with predator)} \\ \frac{dy}{dt} &= -cy + dxy && \text{(predator — dies alone, grows with prey)} \end{aligned}dtdx​dtdy​​=ax−bxy=−cy+dxy​​(prey — grows alone, dies with predator)(predator — dies alone, grows with prey)​
Predator–prey population cycles
When prey peaks the predator grows; when predator peaks prey declines — a lagging oscillation.
