16.1 Vector Fields​

Vector Field:

F(x,y)=P(x,y)i+Q(x,y)j\mathbf{F}(x,y) = P(x,y)\mathbf{i} + Q(x,y)\mathbf{j}F(x,y)=P(x,y)i+Q(x,y)j

Assigns a VECTOR to each point in space.

16.2 Line Integrals​

∫CF⋅dr=work done by F along curve C\int_C \mathbf{F} \cdot d\mathbf{r} = \text{work done by } \mathbf{F} \text{ along curve } C∫C​F⋅dr=work done by F along curve C

(Think: Force dotted with tiny displacement, summed along the path).

Line Integral
Work done by the force field F pushing along the curve C.

Evaluating Line Integrals:

∫CF⋅dr=∫CP dx+Q dy\int_C \mathbf{F} \cdot d\mathbf{r} = \int_C P \, dx + Q \, dy∫C​F⋅dr=∫C​Pdx+Qdy

Parametrize CCC as r(t)=⟨x(t),y(t)⟩\mathbf{r}(t) = \langle x(t), y(t) \rangler(t)=⟨x(t),y(t)⟩:

=∫abF(r(t))⋅r′(t) dt= \int_a^b \mathbf{F}(\mathbf{r}(t)) \cdot \mathbf{r}'(t) \, dt=∫ab​F(r(t))⋅r′(t)dt

16.3 Fundamental Theorem for Line Integrals​

If F=∇f\mathbf{F} = \nabla fF=∇f (the field is conservative, meaning it's the gradient of some scalar potential function fff), then:

∫CF⋅dr=f(r(b))−f(r(a))\int_C \mathbf{F} \cdot d\mathbf{r} = f(\mathbf{r}(b)) - f(\mathbf{r}(a))∫C​F⋅dr=f(r(b))−f(r(a))

KEY CONSEQUENCES: For conservative fields:

  1. The integral depends only on ENDPOINTS, not the path taken (Path Independence).
  2. ∮CF⋅dr=0\oint_C \mathbf{F} \cdot d\mathbf{r} = 0∮C​F⋅dr=0 (The integral around any closed loop is zero).
Path Independence
Both Path 1 (green) and Path 2 (blue) give the same integral if the field is conservative.

16.4 Green's Theorem​

∮CP dx+Q dy=∬D(∂Q∂x−∂P∂y)dA\oint_C P \, dx + Q \, dy = \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dA∮C​Pdx+Qdy=∬D​(∂x∂Q​−∂y∂P​)dA

Converts a LINE integral on a closed boundary curve CCC to a DOUBLE integral over the enclosed region DDD. (Assumes CCC is traversed counterclockwise).

Green's Theorem Region
Boundary C (counterclockwise) encloses Region D.

Great for computing areas:

A=12∮C(x dy−y dx)A = \frac{1}{2} \oint_C (x \, dy - y \, dx)A=21​∮C​(xdy−ydx)

16.5 Curl and Divergence​

CURL: curl F=∇×F\text{curl } \mathbf{F} = \nabla \times \mathbf{F}curl F=∇×F

Measures the ROTATION or "spin" of a vector field at a point.

  • curl F>0\text{curl } \mathbf{F} > 0curl F>0: counterclockwise rotation
  • curl F<0\text{curl } \mathbf{F} < 0curl F<0: clockwise rotation
  • curl F=0\text{curl } \mathbf{F} = 0curl F=0: irrotational (often implies the field is conservative)
  Curl F > 0   Curl F < 0
    (ccw)        (cw)
    ↖ ↑ ↗        ↗ ↑ ↖
    ← · →        → · ←
    ↙ ↓ ↘        ↘ ↓ ↙

DIVERGENCE: div F=∇⋅F=∂P∂x+∂Q∂y+∂R∂z\text{div } \mathbf{F} = \nabla \cdot \mathbf{F} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}div F=∇⋅F=∂x∂P​+∂y∂Q​+∂z∂R​

Measures the OUTWARD FLOW from a point.

  • div F>0\text{div } \mathbf{F} > 0div F>0: Source (flow out)
  • div F<0\text{div } \mathbf{F} < 0div F<0: Sink (flow in)

16.7 Surface Integrals (Flux)​

∬SF⋅dS=∬SF⋅n dS=flux through surface S\iint_S \mathbf{F} \cdot d\mathbf{S} = \iint_S \mathbf{F} \cdot \mathbf{n} \, dS = \text{flux through surface } S∬S​F⋅dS=∬S​F⋅ndS=flux through surface S

Measures how much of the field F\mathbf{F}F "flows through" the surface SSS (using the outward normal vector n\mathbf{n}n).

16.8 Stokes' Theorem​

∮CF⋅dr=∬Scurl F⋅dS\oint_C \mathbf{F} \cdot d\mathbf{r} = \iint_S \text{curl } \mathbf{F} \cdot d\mathbf{S}∮C​F⋅dr=∬S​curl F⋅dS

Relates the LINE integral around a closed boundary curve CCC to a SURFACE integral over any surface SSS that has CCC as its boundary. (Generalizes Green's Theorem to 3D surfaces).

16.9 The Divergence Theorem​

∬SF⋅dS=∭Ediv F dV\iint_S \mathbf{F} \cdot d\mathbf{S} = \iiint_E \text{div } \mathbf{F} \, dV∬S​F⋅dS=∭E​div FdV

Flux through CLOSED SURFACE = integral of divergence over the Enclosed VOLUME.

"What flows out of the surface is equal to what is created inside." (This generalizes the Fundamental Theorem of Calculus to 3D and unifies all the major theorems).
