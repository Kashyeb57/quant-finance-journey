13.1–13.2 Vector Functions and Derivatives​

Vector Function (space curve):

r(t)=⟨f(t),g(t),h(t)⟩\mathbf{r}(t) = \langle f(t), g(t), h(t) \rangler(t)=⟨f(t),g(t),h(t)⟩

Example: Helix

r(t)=⟨cos⁡(t),sin⁡(t),t⟩\mathbf{r}(t) = \langle \cos(t), \sin(t), t \rangler(t)=⟨cos(t),sin(t),t⟩

13.3 Arc Length and Curvature​

Arc Length:

L=∫ab∣r′(t)∣dtL = \int_a^b |\mathbf{r}'(t)| dtL=∫ab​∣r′(t)∣dt

Curvature (κ\kappaκ) measures how sharply a curve bends:

κ=∣r′(t)×r′′(t)∣∣r′(t)∣3\kappa = \frac{|\mathbf{r}'(t) \times \mathbf{r}''(t)|}{|\mathbf{r}'(t)|^3}κ=∣r′(t)∣3∣r′(t)×r′′(t)∣​
  • Low κ\kappaκ: Gentle curve (almost straight)
  • High κ\kappaκ: Sharp curve (tight spiral)
  • κ=0\kappa = 0κ=0: Straight line
  • κ=1/r\kappa = 1/rκ=1/r: Circle of radius rrr
