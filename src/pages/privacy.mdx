# Privacy

*Last updated: September 12, 2026*

This is a personal learning site. It has no accounts, no advertising, and no
cookies. This page describes exactly what it does record, based on how the site
is built.

## Visit statistics

To understand how the site is used, each page view sends a small request to the
site's own server. For every view it records:

- the page address, and the page you arrived from
- your screen size, and how long you stayed on the page
- your **IP address**
- the approximate location Cloudflare derives from that address — country,
  region, city and time zone — and your network provider
- your browser's user-agent string (browser, operating system and device type),
  and your preferred language

It does **not** set cookies, store anything in your browser, or follow you
across other websites.

**Who can see it.** Only the site owner, through a private dashboard protected
by a secret key. It is not sold, shared, or used for advertising.

**Where it is kept.** In a database on Cloudflare, which runs the site's server.

**How long.** Records are kept until the owner deletes them. There is currently
no automatic expiry.

## Services your browser contacts directly

Some features load resources from outside providers. When they do, that provider
receives your IP address and handles it under its own privacy policy.

| Service | When it is used |
| --- | --- |
| Google Fonts | Every page — the site's typefaces |
| jsDelivr | Pages with runnable Python |
| unpkg | The market terminal's price chart |
| allorigins.win and corsproxy.io | The market terminal's news feed |
| Coinbase | Live crypto prices in the market terminal |

Stock quotes, charts and portfolio data are fetched by the site's own server, so
Alpaca and Yahoo Finance never receive your IP address.

The site itself is hosted on GitHub Pages and delivered through Cloudflare, which
process requests in order to serve it.
